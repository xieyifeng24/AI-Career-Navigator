## 可执行路线与情景

### 成长路线 基础

掌握环境科学、基础统计、电子表格、数据单位与监测质量。

验证作品：在公开或明确标记的模拟数据上做废物/水质台账，追踪缺失数据与边界。

目标方向：`environment`。建议不代表实际在招、官方必修或固定年限。

### 成长路线 中级

选定环境监测/GIS或企业气候数据一条主线，不把两者混成一项许可。

验证作品：完成含采样质量说明的空间分析，或有原始凭证与计算边界的排放清单。

目标方向：`environment`。建议不代表实际在招、官方必修或固定年限。

### 成长路线 进阶

补齐行业知识、专业审查经验和适用资格，再承担项目或气候风险管理。

验证作品：做项目级质量审查与客户说明；金融路径另补财务、风险和本地气候框架。

目标方向：`environment`。建议不代表实际在招、官方必修或固定年限。

### What If A

掌握AI抽取与核查工具：可改善报告字段整理和缺漏检查；前提是授权资料、逐项校验和可追溯。

验证作品：比较源文件与抽取值，记录错单位、缺值和错误引用。

目标方向：`environment`。条件情景，不生成匹配分、就业概率或工资增幅。

### What If B

掌握GIS与统计质量控制：更易承担监测、空间分析和环境数据任务；现场与专业知识仍需培养。

验证作品：提交含坐标、采样偏差与不确定性的分析图和方法说明。

目标方向：`environment`。条件情景，不生成匹配分、就业概率或工资增幅。

### What If C

完成SQL/Python环境数据仪表盘：可探索数据分析师；补SQL查询、统计与业务沟通，领域项目可作证据。

验证作品：交付数据字典、更新脚本、异常检查与可复现图表。

目标方向：`data`。条件情景，不生成匹配分、就业概率或工资增幅。
