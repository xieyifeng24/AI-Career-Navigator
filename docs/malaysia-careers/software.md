## 可执行路线与情景

### 成长路线 基础

先掌握Python或JavaScript其中一种、数据结构基础、SQL、Git和测试。

验证作品：用公开数据做小型API与网页，保留需求、代码审查和测试记录。

目标方向：`software`。建议不代表实际在招、官方必修或固定年限。

### 成长路线 中级

学习部署、数据库迁移、日志、鉴权与性能。

验证作品：为项目增加CI测试、错误告警和恢复说明，解释一个业务取舍。

目标方向：`software`。建议不代表实际在招、官方必修或固定年限。

### 成长路线 进阶

积累系统设计、安全审查和跨团队需求协商。

验证作品：写架构决策记录，验证故障、成本与访问控制。

目标方向：`software`。建议不代表实际在招、官方必修或固定年限。

### What If A

掌握AI编码助手和验证流程：可提升样板代码、测试和错误解释能力；前提是能独立复现并审查输出。

验证作品：比较人工与AI草稿的测试覆盖、缺陷和耗时；不承诺提升百分比。

目标方向：`software`。条件情景，不生成匹配分、就业概率或工资增幅。

### What If B

掌握SQL与API设计：更易满足后端/全栈任务要求；需证明数据建模、鉴权与错误处理。

验证作品：交付有测试的API和数据库迁移，不以证书代替。

目标方向：`software`。条件情景，不生成匹配分、就业概率或工资增幅。

### What If C

完成带监控的模型API项目：可进一步探索AI／机器学习工程师；额外补统计、评估和数据泄漏检查。

验证作品：项目须有基线、API、模型卡与错误分析，不能只调用黑箱API。

目标方向：`ai-research`。条件情景，不生成匹配分、就业概率或工资增幅。
