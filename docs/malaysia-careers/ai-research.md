## 可执行路线与情景

### 成长路线 基础

先掌握Python、线性代数、概率统计、SQL和训练/验证划分。

验证作品：以OpenDOSM公开数据做可复现基线，避免时间泄漏；解释模型不适用场景。

目标方向：`ai-research`。建议不代表实际在招、官方必修或固定年限。

### 成长路线 中级

将模型变成API，加入容器、评估、监控与成本记录。

验证作品：做双语或三语RAG实验，记录检索准确性、拒答与错误案例。

目标方向：`ai-research`。建议不代表实际在招、官方必修或固定年限。

### 成长路线 进阶

掌握MLOps、业务风险、隐私和治理，形成行业专业知识。

验证作品：对模型更新建立审批与回滚实验，解释模型价值与成本。

目标方向：`ai-research`。建议不代表实际在招、官方必修或固定年限。

### What If A

掌握AI实验助手：可提升数据脚本与模型文档初稿能力；前提是验证泄漏、统计和结果。

验证作品：保留实验日志和人工复核记录，不报成功概率。

目标方向：`ai-research`。条件情景，不生成匹配分、就业概率或工资增幅。

### What If B

掌握部署监控与SQL数据管线：更易满足本地AI工程交付任务；需能解释故障、成本与漂移。

验证作品：训练与服务数据一致性测试、异常告警和回滚演练。

目标方向：`ai-research`。条件情景，不生成匹配分、就业概率或工资增幅。

### What If C

完成公开环境数据的预测/异常项目：可探索环境／可持续发展分析师；须补环境采样、数据单位和领域解释。

验证作品：环境专业人员核验模型错误和业务含义；不能仅靠模型输出签署报告。

目标方向：`environment`。条件情景，不生成匹配分、就业概率或工资增幅。
